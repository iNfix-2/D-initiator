DigiVolt

A live dispatch workspace for electric fleets.

Project
DigiVolt
Type
Mobility systems
Role
Senior web developer and UI architect
Stack
WebSockets, GPS telematics

The brief

Give transit operators one place to follow vehicles, monitor batteries and coordinate electric shuttles and tricycles.

The build

I built the dispatch interface around the map. A lightweight WebSocket connection delivers position updates, battery readings and arrival estimates without reloading the dashboard.

The design had to work on low-bandwidth connections. Keeping changing telemetry separate from the rest of the interface lets dispatchers keep their place while fleet data updates.
