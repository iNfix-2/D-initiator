Everything Kaduna

A searchable directory of Kaduna businesses.

Project
Everything Kaduna
Type
Local discovery
Role
Full-stack developer
Stack
React, tRPC, Drizzle ORM, MySQL

The brief

Help people find local businesses across Kaduna and give merchants a way to create a verified listing.

The build

I connected the React interface to a MySQL directory through tRPC and Drizzle ORM. A shared type system keeps the search results and listing records in step.

The merchant onboarding flow includes verification, so the directory can distinguish a reviewed listing from a newly submitted one.
